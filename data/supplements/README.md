# 官方文字补充题库

来源：<https://xyq.163.com/tools/>，核对日期 2026-10-03。

`text_questions.json` 收录原库未包含的 580 条题干及答案记录，包括
195 条去掉“寻梦古蜀”分类前缀后的题干版本。`metadata.json` 保留
来源、原网页摘要、数量、记录摘要以及缺字恢复的来源记录。

首次正常启动会在题库加载前补齐旧数据目录中缺失的文字补充，也支持
配置中的自定义数据目录。已有补充按规范化题干和答案增量合并，保留
自有记录和本地补题；重复启动不会重复写入。

初始库继续使用上述平铺文件。增量升级会先写完整、校验通过的新
`generations/<编号>/`，再原子切换本目录的 `current.json`。
加载器优先读取补充指针，没有指针时兼容平铺文件。旧文件和旧
generation 保留；写入、校验或指针切换失败时不覆盖旧库。

程序与原官方题库合并加载，不改变原官方快照。刷新原官方题库时
保留此目录，按规范化题干和答案去重。详细比较说明见
`docs/2026-10-03-official-tools-bank.md`。
