# CPU 与 GPU 预览框选一致性

两条绘制路径统一使用 #ef4444 红色、向内绘制的矩形边框。高可信结果使用实线，候选使用虚线；边框不再包含可信等级和分数文字，评分不再影响框的颜色或粗细。识别门槛、状态及诊断数据不变。

边框粗细按显示区域的实际像素计算：max(3, floor(显示宽度 / 400))。虚线长度为三倍粗细，间隔为两倍粗细。软件 overlay canvas 使用显示区域与 DPI 对应的分辨率，不再跟随 640/1024 像素的视频预览位图缩放。两条路径均按 contain 缩放并水平、垂直居中。

已核对 640/1024 预览输入及 1/1.25/1.5/2 倍 DPI 的几何结果；Web 相关回归 50 项通过，原生辅助程序编译通过。本次去除的是预览框旁标签，侧栏诊断信息仍保留。
