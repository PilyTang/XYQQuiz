# 低配模式与预览暂停

性能设置新增 `performance.low_resource_mode`，默认 false。保存或重启沿用原有后端设置流程；旧客户端只保存 OCR/预览后端时也保留该开关，适配器迁移不会清掉它。

低配模式只对本次服务图的配置施加上限：预览 10 FPS、识别扫描 5 FPS。用户手动设置的更低频率不提高。正常模式原配置不被写成限速后的值，关闭开关并重启即可恢复。软件预览缩至最多 640 像素宽；原生 GPU 预览仍使用纹理绘制，通过实际渲染节拍限速。识别图像维持原始分辨率，OCR 线程数和匹配门槛不变，显卡优先逻辑保留。

暂停预览、隐藏页面或打开模态弹窗时，页面报告预览不可见。软件流在转换、发送前等待，恢复后只取最新帧；硬件流恢复时重新请求关键帧。桌面窗口的最小化/恢复事件另行通知服务，防止 WebView2 未及时产生 visibilitychange。状态流和识别服务继续工作。

原生预览在不可见时跳过提交纹理和渲染，使用最多 100 毫秒的可唤醒等待替代频繁重试，恢复布局时重新使用已保留的最新纹理。原生预览由独立 OCR 捕获供帧时，不再唤醒无实际任务的 CPU 帧处理队列。

本阶段不裁剪游戏捕获区域，也不改变图标匹配流程。隐藏预览仍保留识别需要的画面捕获；它减少的是显示相关开销，不能保证某台低端机的 OCR 耗时或总体 CPU 必然下降到固定数值。

验证覆盖：开关持久化/恢复、低于默认的自定义频率、GPU 默认选择保持、服务实际频率和软件尺寸上限、隐藏状态不转换画面、恢复使用最新帧、桌面最小化事件、暂停不停止识别服务。原生辅助程序须重新编译；低端机器实际收益仍需同场景测量。
