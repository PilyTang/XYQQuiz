# 教师节连续答题的鼠标遮挡容错

## 原因

教师节题目身份同时比较技能图标和四个选项的文字像素。选项原有容差仅约 0.2%，游戏绘制的彩色鼠标覆盖部分文字时，会被当成换题并清除框选。WGC 已禁用系统鼠标捕获，但无法去除游戏画面内部绘制的鼠标。

## 处理

- 仅对已经产生答案或候选框选、题框连续可见的当前题启用容错。
- 在选项文字区域检测小范围高色差覆盖，包含少量边缘保护；对照此前未遮挡的题面，忽略该区域的像素差异。
- 技能图标、其他三个选项、受遮挡选项的其余文字及题框几何位置仍须满足原有比较条件。
- 初次识别、历史缓存匹配及未完成识别的结果不使用这一保留旧框选的策略。
- 不降低扫描频率，不延迟真实换题的清除，也不因符合条件的鼠标移动重新运行 OCR。

这属于针对默认彩色游戏鼠标的局部遮挡处理，尚未使用用户本次实际录屏验证。大范围覆盖、同时遮挡多个选项、灰度鼠标或首次识别时已遮住文字，不在这一保留已有框选的策略范围内。完全藏在鼠标下的文字变化无法单凭当前画面判定，因此不允许该策略建立新的答案或复用历史缓存。

## 新题出现时已有遮挡

当前帧的四个选项中，允许恰好一个为空或 OCR 置信度低于 0.8，其他三个选项必须可读。已有文字的四个选项统一参与图标与名称相似度比较，不因某个干扰项低可信而关闭近似匹配。沿用图标强度、文字相似度和第一第二名分差门槛，选中的答案选项自身仍须达到 0.8；近似匹配只显示候选虚线框。

如果一个选项完全为空，仍采用原有部分选项路径，只允许选择与图标名称精确相符的可读选项；图标须达到 0.72，并领先其他技能至少 0.10，空白项场景不启用近似文字候选。

答案选项本身低可信、两个以上选项读不清、重复选项、图标或文字评分无法拉开差距时，继续等待。低可信选项仍参与比较，因此不会把接近答案的干扰项丢掉后制造唯一候选。不会用排除法选择不可读位置，也不会拿上一题文字补足新题。置信度使用可读选项计算。

## 回归覆盖

四个选项、0.8/1/1.5 倍题框、重复扫描与鼠标跨选项移动；严格缓存拒绝遮挡帧；新图标、其他选项变化和大面积覆盖仍使连续性失效。协调器集成测试验证框选和代次保持、OCR 调用不增加，以及新图标立即清除框选。
