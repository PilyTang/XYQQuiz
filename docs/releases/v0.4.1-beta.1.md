# XYQQuiz 0.4.1 Beta 1

本次为教师节“看图说话”公开测试版，包含 v0.4 教师节功能及三题用户反馈的漏识别修复。

## 更新内容

- 自动识别科举与教师节活动，无需手动切换。
- 内置 336 条教师节技能图标记录，结合图标与四个选项匹配答案。
- 修复“堪察令/勘察令”“中药医理/中医药理”的名称差异，以及未收录干扰项导致整题无法识别的问题。
- 切题、调整选项顺序、关闭题面和更新题库时及时清除旧提示。
- 教师节题库独立更新，完整下载并校验成功后切换；失败时保留原题库。

## 下载与升级

下载 `XYQQuiz-v0.4.1-beta.1-win10-win11-x64.zip`，可用同名 `.sha256` 文件校验完整性。解压到新目录后运行 `XYQQuiz.exe`，不要覆盖正在运行的旧目录。

本次修复属于程序逻辑，旧版程序仅点击“更新题库”不会获得修复。

## 验证范围

发布工作流会在 Windows 上运行全量测试、公开树审计、便携包构建与 headless 自检，通过后才上传附件。源码保留了三题反馈的脱敏裁剪回归资源。

教师节优先支持 1024×768 及以上游戏画面。活动现场长时间连续答题、更多 DPI/窗口组合和 Windows 10 实机仍需继续验证；如遇漏识别，请保存程序的完整识别诊断以帮助区分题面定位、OCR 和匹配问题。

工具只显示候选答案，不自动点击游戏。此版本标记为 Pre-release，不替换 GitHub 的稳定版 Latest。
