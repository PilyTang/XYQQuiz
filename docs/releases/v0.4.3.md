# XYQQuiz 0.4.3

- 修复解压到中文目录后出现“anchor 不可读”的启动错误，自检同步覆盖定位资源。
- 改善关闭窗口后的后台退出：限制请求等待时间，调整原生预览关闭顺序。
- OCR、预览的默认“自动”选项改为显卡优先。OCR 优先使用专用显存较大的 DirectML 显卡，失败后尝试其他显卡，全部失败才回退 CPU；预览优先使用游戏窗口所在显示器的显卡。手动 CPU 设置继续保留，保存设置后下次启动生效。
- 修复回退 CPU 后被后台自检错误显示为 GPU 的状态问题。
- 教师节新增 18 条补充技能，总计 354 条记录、353 个不同技能名。补充库独立存放，不被更新网易题库覆盖。

下载 `XYQQuiz-v0.4.3-win10-win11-x64.zip`，完整解压到新目录后运行 `XYQQuiz.exe`。同名 `.sha256` 可用于校验。点击“更新题库”仅更新数据，不能升级程序。

本轮功能全量回归 679 项通过、3 项因缺少私人截图跳过；版本提升另校验项目元数据、Windows 文件版本和新构建 EXE 自检。Windows 10 实机、全部显卡驱动与长期活动现场仍需继续验证。

OCR 沿用 PP-OCRv6 small。固定对比度增强在部分科举历史样本上增加错字，本版保留原图处理为默认。
