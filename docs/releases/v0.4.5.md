# XYQQuiz 0.4.5

本版改善教师节连续答题与额外补充图标的识别。

- 已识别出答案后，一个选项内的小范围彩色鼠标遮挡不再立即清除框选；图标和可见文字变化仍检查。
- 新题有一个选项读不清时，如果当前图标与某个可读选项精确对应，且图像证据唯一、高可信，可以显示答案。答案本身不可读、多个选项不可读或存在歧义时继续等待。
- 18 个补充技能同时用网页原图和去装饰边框的主体版本匹配。“吃茶去了”反馈截图已恢复为高可信的 B 选项。
- 保留原有匹配门槛、原始图标校验和 supplements 独立存储。官方题库更新不会覆盖该处理。

本地修订包补充：图标边框兼容已统一应用到全部来源，使用原图、薄边框主体和装饰边框主体版本。覆盖全部 18 个非官方补充技能及后续新增来源，并修复官方“牛刀小试”69 像素诊断裁剪未匹配的问题。相关回归 141 项通过。

细节见 [鼠标遮挡容错](../teacher-cursor-occlusion.md) 和 [补充图标处理](../teachers-day-supplement-icons.md)。

**已知问题：Windows 10 1909（18363.657）出现的 windows_capture.pyd / 0xC0000409 崩溃仍在排查，本版未修复该问题。** Windows 11 本地打包验证不能替代该用户环境的实机验证。

完整解压 `XYQQuiz-v0.4.5-win10-win11-x64.zip` 到新目录后运行 `XYQQuiz.exe`。这些修复需要新版程序，单独“更新题库”不会升级匹配器。
