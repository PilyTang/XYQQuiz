# XYQQuiz 0.5.0

本版整合首次硬件自动选择、低配模式、统一预览框选，以及教师节识别修复。

- 首次运行优先选择低配模式。只有 CPU 至少 12 个逻辑线程、已安装内存至少 16 GiB，并检测到硬件图形适配器时，才自动选择标准模式。硬件信息不完整时选择低配。
- 自动结果保存在配置中，只执行一次；旧版明确保存的高低配选择及用户后续手动设置不会被覆盖。性能设置会显示自动选择原因。
- 低配模式将预览限制为最高 10 FPS、软件预览宽度最高 640 像素，识别独立以最高 5 FPS 检查新题，并保留原始文字图像。显卡优先及失败回退策略保留。
- 暂停预览、隐藏页面及最小化时，识别和答案文字仍继续更新。恢复后取最新帧，启动时主动隐藏不会误触发硬件预览超时。
- CPU/GPU 使用相同红色边框、粗细和居中对齐。框旁不再显示可信等级和分数；候选保留虚线，侧栏诊断信息保留。
- 整合教师节鼠标局部遮挡容错；一个选项不可读时仅凭当前可见证据确认答案；全部来源图标使用原图、薄边框主体、装饰边框主体共同匹配。
- 18 个非官方补充技能独立保存，官方题库更新不会覆盖；原始资源和校验值保留，题库合并后共 354 条记录。

硬件阈值是保守初始规则，不是跑分或速度保证。低端机实际收益需同场景测量。

**Windows 10 1909（18363.657）的 windows_capture.pyd / 0xC0000409 崩溃尚未修复。**

完整解压 `XYQQuiz-v0.5.0-win10-win11-x64.zip` 到新目录运行。需要保留原有设置时可迁移旧配置；其中明确保存的高低配开关会继续沿用。单独“更新题库”不会升级程序。
