# XYQQuiz 0.5.9

发布日期：2026-10-11。

## 本次更新

- 补充网易官网综合工具箱的 580 条文字题干与答案记录，内置可用文字记录从 2,586 条增至 3,166 条。包含 195 条已有“寻梦古蜀”题目的无前缀题干版本。
- 增加 82 张教师节技能图像版本，有效图标记录从 367 条增至 449 条，覆盖 366 个名称。保留既有补充和错误图排除规则。
- 独立文字补充库校验数量和 SHA-256；官方题库刷新仍保留补充，上游收录同题同答案后自动去重。
- 修复旧数据目录遗漏新版文字补充的问题：升级后首次正常启动自动补齐，支持自定义数据目录；已有补充增量合并，保留原官方快照和本地补题，失败时保留旧库。
- 改进本地识别诊断，画面、题目及选项裁剪、布局和识别结果对应同一识别场景；没有一致场景时不附上过期识别结果。诊断仍由用户操作保存到本地。

题库来源及排除项见 [官网题库补充记录](https://github.com/PilyTang/XYQQuiz/blob/main/docs/2026-10-03-official-tools-bank.md)。

## 使用与升级

下载 `XYQQuiz-v0.5.9-win10-win11-x64.zip` 和同名 `.sha256`，核对校验值后完整解压到新目录，再启动 `XYQQuiz.exe`。

按需复制旧目录中的 `config.json`、`data` 和 `user-data`；首次正常启动会补齐缺失的内置资源及文字补充。不要将新版 EXE 或 `_internal` 覆盖到旧版目录。“更新题库”不会更新程序。

## 验证与边界

发布前源码完整回归：838 passed、3 skipped；跳过项依赖未公开的真实截图语料。最终发布提交的 CI、冻结包自检与校验结果以对应 GitHub Actions 和附件为准。

Windows 10 1903 及以上 x64、Windows 11 x64 为目标范围。Windows 10 1909（18363.657）的 `windows_capture.pyd / 0xC0000409` 崩溃仍待修复；本轮没有新增 Windows 10、多设备/DPI 或活动现场连续答题验收。

元宵题目数据收录不代表元宵活动界面已完成适配；“谁是学霸”判断题仅独立归档，运行时未启用。图像裁边过深或证据不足时仍会拒答。
