# XYQQuiz 0.4.4

本版重点降低等待答题界面出现时的 CPU 占用。

- 教师节题框搜索先在缩小图中找候选，再在原始画面的局部区域精确校验，减少重复的全画面匹配。
- 缓存不同尺寸的定位模板，已找到题框时继续使用小范围追踪。
- 修复普通画面仅因标题相似而被误判为“疑似教师节”的问题，保留对部分题框的保护。
- 题框出现、移动、关闭仍及时检测，不降低预览帧率与新题扫描频率。

保留 0.4.3 的显卡优先、中文路径和退出修复，以及 354 条教师节记录。18 个补充图标独立保存，不会被网易题库更新覆盖。

在同一批 15 帧本机画面中，全局搜索中位耗时从约 199ms 降至 64ms。实际整体 CPU 占用随游戏画面、分辨率和硬件变化，不能将此降幅直接等同于整机 CPU 降幅。全量回归 686 项通过，3 项因缺少私人截图跳过；发布流程另验证打包后的 EXE 自检及 SHA-256。

下载 `XYQQuiz-v0.4.4-win10-win11-x64.zip`，完整解压到新目录运行 `XYQQuiz.exe`。同名 `.sha256` 文件可校验完整性。程序升级需要下载新包，“更新题库”不会升级程序。

支持 Windows 10 1903+ / Windows 11 x64；Windows 10 实机和更多显卡、DPI 组合仍需继续验证。
