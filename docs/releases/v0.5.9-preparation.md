## 已完成、拟纳入 0.5.9 的内容

1. 官方文字题库补充：从 2,586 条增至 3,166 条，添加 580 条记录，
   包括元宵区 372 条、科举区 208 条。其中 195 条是已有题目去掉
   “寻梦古蜀”前缀后的题干版本，不能宣传为 580 道全新知识题。
2. 教师节图像补充：新增 82 张技能图像版本，合并后为 449 条图标记录、
   366 个名称。原补充 32 条、新补充 82 条，共 114 条；有效官方库仍为 335 条。
   继续排除错误的“佛法无边”原图，并保留原有安全拒答规则。
3. 独立文字补充库：校验 SHA-256 与数量，加载时合并，原官方题库刷新
   不覆盖补充；上游以后收录同题同答案时自动去重。构建清单记录原库和有效库数量。
4. 本地识别诊断：保存与识别结果对应的画面、题目/选项裁剪和布局，
   不混用点击导出时的另一帧或另一道题。没有一致场景时不拼接过期识别结果。
   诊断依然只写本地文件。
5. 来源与追溯：保存官网来源、数量、图片和记录摘要、缺字恢复记录及排除项，
   同步第三方内容说明。
6. 2026-10-11 修复旧数据目录升级：正常启动在首次加载题库前补入新版文字
   补充，支持自定义目录；已有补充增量去重合并，保留自有记录、本地补题、
   原官方指针与快照。完整新补充库校验后才切换，失败保留旧库。

题库细节见 [官网题库补充说明](../2026-10-03-official-tools-bank.md)。

## 保留的兼容性边界

- Windows 10 1909 的 `windows_capture.pyd / 0xC0000409` 崩溃仍未修复。
- 本轮没有新增 Windows 10、多设备/DPI、低端机或活动现场连续答题验收。
- 裁边过深、图文歧义或证据不足时仍不提供答案，不通过降低阈值扩大提示范围。
