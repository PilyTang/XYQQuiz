# XYQQuiz 0.5.2 本地验证版

- 新增可开关的性能记录模式：逐题记录稳定等待、识别排队、OCR、图标匹配、后台答案接受和前端回执。
- 记录每次重试及四个选项的 OCR 执行、排队和回退次数；支持导出 JSON 明细及 CSV 中位数/P95/最大值报告。
- 默认关闭，仅保留有界内存数据，不保存截图、题目、答案或账号信息；退出前需导出，重新开始清空上一轮。
- 保留 0.5.1 的标准模式动态取帧修复。原生画框指令回执不代表显示器精确呈现时间。

操作及指标边界见 [性能记录说明](../performance-recording.md)。Windows 10 1909 原生捕获崩溃仍未修复。
