## 优化顺序建议

1. 先补齐已确认缺失图标，避免对相同缺库题反复执行 OCR 和匹配。本次“以和为贵”仅补图后即可达到 96.11 分。
2. 优化图标匹配中不随画面变化的工作，例如预计算模板的灰度、边缘及归一化特征；保留所有图标变体和原判定阈值，以回放结果一致为前提。
3. 稳定等待与识别可探索并行：第一帧提前计算，第二帧确认后才显示。但应先补充题面失效原因与跨题相对时间，确认 pending 记录来源，避免提前识别增加无用工作。
4. 检查结果完成事件唤醒，减少约 16.5 ms 的结果接收等待；仍须先处理新帧失效，不能让旧答案闪回。
5. OCR 批量化、预览降帧和更换模型暂不优先。现有数据中的布局定位、OCR 和 UI 回执开销都明显小于图标匹配及稳定等待。
