# v0.4 教师节实现与验收

日期：2026-09-01。代码基线为 v0.3.1，工作分支 `codex/v0.4-teachers-day`。

## 实现范围

教师节与科举自动分流。教师节先定位完整答题框，截取技能图标并读取四个选项，再做图标与名称联合匹配。颜色、图标内部结构和边缘共同评分；图标空白、选项缺失/重复/不在题库或图像证据冲突时不输出答案。

内置 336 条官方图标记录、335 个不同名称、25 个分类。同名“破釜沉舟”的两条记录保留不同图标。教师节数据独立存放在 `data/teachers_day`，采用 generation 目录与原子指针，联网更新完成全部图片校验后切换。旧配置缺少资源时从内置数据补齐，损坏时尝试上一有效版本或内置版本。

连续识别使用图标与选项文字区域共同判断题目身份，排除背景、连对计数和按钮边缘。切题、调整选项顺序、关闭题面、活动切换和更新题库会使旧结果失效；两种活动共用原有单线程 OCR 实例。

## 自动化验证

- 修改前基线：581 passed、3 skipped。
- 本轮全量：625 passed、3 skipped。跳过项为未提供私人真实截图 fixture 的既有集成测试。
- 全量后针对诊断、构建、自检、识别及 Web 接口的复验：83 passed。
- 桌面窗口与启动器标题统一后的相关回归：59 passed。
- 新增 44 项测试覆盖解析路由模块、字段顺序变化、重复名称/编号、图片失败保留旧版本、损坏恢复、旧配置补齐、图像证据不足、选项顺序变化、多分辨率定位、连续切题时延迟结果作废，以及两套题库独立更新结果。
- 官方在线更新实测：336 条记录和 336 张图片全部下载并校验成功，发布后重新加载 generation 一致，耗时约 3.34 秒。

## 真实截图回放

原始截图仅用于本机回放，未进入源码、内置资源或发布包。定位锚点只保留不含角色、聊天信息的标题、提示和退出按钮小图。

| 样本 | 正确技能 | 输出选项 |
| --- | --- | --- |
| 1 | 连环击 | D |
| 2 | 健身术 | B |
| 3 | 百毒不侵 | C |
| 4 | 古董评估 | D |

四张原图经实际 RapidOCR 与完整 RecognitionPipeline 均得到高可信正确答案。另将每张截图中自动定位的答题框放入不同画布并缩放，共 24 个场景全部通过：原图、1024×768/1280×960/1920×1080 的原比例题面、1920×1080 的 1.5 倍题面，以及 1024×768 的 0.8 倍题面。合成画布只验证定位、缩放和 OCR，不等同于这些游戏分辨率的实机测试。

实际状态机连续回放四张截图并交换第四题 A/D：输出 D、B、C、D、A。预热后每题从发布帧到状态返回正确答案约 223～365 毫秒；已有答案的清除约 60～83 毫秒，关闭答题框约 73 毫秒。首次发现题面没有旧答案可清除。该样本量用于检查处理链路，不作为充分的 P95 性能保证。

当已定位题面突然大幅移动或缩放时，先清除旧框，后续帧全局重新定位。静态单张图独立测试从冷定位开始。

脱敏的机器可读结果在 `docs/evidence/v0.4-implementation.json`。

## 界面与交付

本地服务通过正常会话启动，在浏览器中检查了 1024×768 和默认 1440×900 尺寸。当前活动、健身术答案、B 选项框、图标评分和两套题库统计与后端一致；窄窗口侧栏可滚动。预览保持原有缩放映射。浏览器验证服务使用静态帧注入，未操作游戏。

便携包为未提交工作区生成的开发验证包，版本 0.4.0；不代表已发布正式版本。

便携包大小 152,680,619 字节（约 145.6 MiB）。SHA-256：

解压后运行 EXE 的 headless 自检退出码为 0：8 项通过，1 项交互式 WGC 检查按模式跳过；1287 个不可变文件的大小及摘要、两套题库、教师节匹配器和定位资源、WebView2 依赖、OCR 推理及本机会话安全均检查通过。未执行真实游戏捕获。

## 尚未验证的边界

- 活动现场长时间连续答题、真实游戏设置下的 DPI/窗口尺寸组合。
- 四张截图之外的所有技能在实际游戏里的显示变体；官方图标可完整加载，但不能把资源完整性当作全题型准确率。
- Windows 10 实机。当前验证在 Windows 11 x64 完成。

这些边界不影响本轮代码、离线资源和试用包交付，后续可用真实活动诊断继续校准。
