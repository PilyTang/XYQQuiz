# 默认显卡优先

默认配置仍为 `ocr_backend: auto` 和 `preview_backend: auto`，现在两项都优先使用显卡。原先保存的 `auto` 随程序升级采用新行为；手动保存的 `cpu` 继续使用 CPU。设置界面将自动项显示为“自动（显卡优先）”，保存仍在下次启动生效。

## OCR

发现 DirectML 提供程序后，按专用显存从大到小、相同显存按 DXGI 编号排列显卡。显卡编号保持 DXGI/DirectML 对应关系；该顺序是设备选择策略，不代表实测速度排名。

程序预热时优先尝试第一块显卡，实际推理后校验检测、分类和识别所用的执行提供程序。如果构建、推理或提供程序校验失败，尝试下一块显卡；全部不可用后回退 CPU。失败的路径本次进程不再重试。手动指定显卡失败时直接回退 CPU，不改写用户保存的选择。

后台可用性自检只更新设备是否可选，不再改变当前运行后端，修复“已经回退 CPU，自检成功却重新显示 GPU”的状态错误。

## 预览

桌面模式且原生辅助程序存在时，`auto` 选择 Windows 硬件预览。原生程序优先使用游戏窗口所在显示器对应的显卡，找不到匹配显示器时选择首个适配器。外部浏览器、辅助程序缺失或捕获运行失败时回退普通预览，保留自动设置。

OCR 与预览仍独立，可能使用不同显卡。布局定位、题库匹配等 CPU 工作不因 OCR 选择而迁移至显卡。

## 验证

后端选择、配置和 OCR 专项 71 项通过，覆盖多显卡顺序回退、全部失败回退 CPU、手动 CPU、DirectML 缺失、提供程序检查异常、硬件预览失败，以及后台自检不覆盖运行状态。

全量测试：679 passed、3 skipped；跳过项依赖未提交的私人完整截图。

本机真实自动 OCR 使用 `DirectML — NVIDIA GeForce RTX 5080` 完成推理，实际提供程序校验通过；后台硬件预览自检也通过。这不替代所有显卡驱动及游戏现场的长时间验证。
