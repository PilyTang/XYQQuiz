# 独立配置 OCR 与预览执行后端

XYQQuiz 分别配置 OCR 执行后端和预览执行后端，不提供含义模糊的全局 CPU/GPU 开关。每项设置包含默认的自动后端策略、CPU，以及当前机器上实际初始化并通过最小自检的设备级加速选项，例如 `DirectML — NVIDIA GeForce RTX 5080`；未通过自检的后端与设备组合不能作为新的可选项。如果用户已经保存的组合后来失效，它仍以“当前不可用”的禁用项显示，并与实际 CPU 回退及原因一起呈现。

自动后端策略在不阻塞首次启动的后台基准中比较可用组合，并按显卡、驱动、程序与运行时版本缓存结果。首次启动或没有有效缓存时，本次运行立即使用 CPU，后台结果只影响下一次启动。用户选择“保存”时只更新待生效后端组合，下次启动生效；选择“应用”时先确认，再自动重启程序使其生效。启动或运行中发生加速故障时，仅对应能力回退 CPU，保留用户保存的选择，本次运行不再自动切回故障后端。

OCR 后端可使用固定样本低优先级静默评估；预览后端的全应用 CPU 基准必须在真实游戏画面上依次测量 CPU 与硬件预览。自动评估只在游戏窗口稳定且没有答题界面时进行，预览评估可以短暂受控切换并显示低调状态；任何评估一旦检测到题目都立即中止并恢复正常答题资源。评估不修改用户设置，结果只供自动模式在下次启动使用；同一显卡、驱动、程序和运行时组合只自动执行一次，设置中允许手动重新评估。

界面分别展示用户请求、当前实际后端、具体加速设备和回退原因；主界面只持续显示低调的运行后端状态，详细自检与基准结果放在设置和诊断视图中。

主界面紧凑运行后端状态的右端提供设置入口。点击小齿轮后打开居中弹窗，集中展示 OCR 与预览选择器、当前与待生效组合、自检和基准状态、重新评估操作，以及取消、保存和应用三个动作；设置不以内联卡片继续拉长右侧栏或挤占游戏预览区域。

“应用”确认中必须说明程序将立即重启，并可能再次出现 Windows 的管理员权限确认。若自动拉起失败，已经保存的选择继续作为待生效组合保留，错误提示应明确告知用户手动重新启动；不能静默覆盖为 CPU 设置。

发布只提供一份便携 ZIP，同包携带 CPU 与 DirectML OCR 能力、C++ 硬件预览辅助进程和现有 CPU 回退路径，不拆分 CPU/GPU 下载，也不在运行时下载加速组件。当前机器的自检与基准结果只决定设置中显示和自动选择哪些后端及设备。

发布的强制硬件门禁只有两套：通用 CPU 模式必须通过完整识别、设置、诊断、回退、打包和隔离环境测试；本机 RTX 5080 加速模式必须通过 DirectML OCR、Windows 硬件预览、平面帧 WebCodecs、30 FPS、延迟、CPU 降幅和故障回退测试。AMD 核显可作补充测试但不阻塞发布，Intel 不作实机认证；发布说明不得把运行时自检能力表述为所有显卡型号均已认证。预览传输格式按 ADR 0005 执行。
